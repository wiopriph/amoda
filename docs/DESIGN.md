# Дизайн-система Amoda

Негласные правила, по которым свёрстан сайт. Проверяй новый экран по этому списку, прежде чем изобретать своё.

## Тон и язык

- Все тексты для клиентки - на "tu": "escolhes", "pagas", "a tua seleção". Никаких "você", "consigo", "digite".
- Тексты человечные, без маркетингового шума. Одно сообщение звучит на странице один раз: если "sem pagamento online" уже сказано в hero, не повторять его в соседней секции.
- Терминология: "Pedidos" (заказы в кабинете), "Reserva" (публичная страница заказа), "Escolha" (корзина), "Showroom" (точка примерки, не "ponto de levantamento").

## Цвет

- Акцент primary (розовый, `#f6339a`) - только у кликабельного и у активного состояния. Цена, заголовки, основной текст - никогда не розовые.
- Цена - главный текст карточки и страницы: чёрная, жирная (`font-extrabold text-highlighted`).
- Зелёный (`color="success"`) - только WhatsApp-действия.
- Серые: рамки `border-gray-100`, подложки `bg-gray-50`, вторичный текст `text-muted`, третичный `text-dimmed`.

## Всё, что лежит на фото

Единый приём - тёмная пилюля:

- Контейнер: `rounded-full bg-black/40 backdrop-blur`, содержимое белое.
- Бейджи товара: пилюля + цветная точка `size-1.5` + подпись `text-[9px] font-bold text-white`. Цвет только у точки: novo `bg-green-400`, sale `bg-red-400`, hot `bg-amber-400`. Утилиты в `app/utils/productBadges.ts`.
- Избранное: `FavoriteToggle` - тёмный круг `size-8 bg-black/40`, белое сердце, активное розовое.
- Счётчик фото, контролы лайтбокса - те же пилюли `bg-black/40`.

## Карточки и секции

- Карточка товара (`ProductCard`): фото-доминанта 4:5 без отступов (flush), под фото цена `text-sm font-extrabold text-highlighted`, название мелко `text-[11px] text-muted truncate`. Контейнер `rounded-2xl border border-gray-100 bg-white`, ховер `hover:shadow-md` + зум фото.
- Категория везде одинакова: фото 3:4 + имя белым на градиенте `from-black/55` снизу. Активная - кольцо `ring-2 ring-primary`.
- Рамки (`border border-gray-100`, `rounded-2xl`) - только у карточек контента. Секции страницы ("Como funciona", "Descrição") рамок-обёрток не имеют.
- Акцент-контейнер (розовый градиент `from-pink-50 via-white to-fuchsia-50` + `border-pink-100 rounded-3xl`) - один на страницу, это hero/шапка страницы.

## Типографика и ритм

- Заголовок секции: `text-2xl font-black tracking-tight text-highlighted sm:text-3xl`.
- H1 страницы товара - скромный: `text-lg font-medium`, потому что главное там цена и фото.
- Вертикальный ритм секций: `mt-6 sm:mt-10`.
- Сетка каталога: `grid-cols-2 gap-3 sm:grid-cols-3 sm:gap-4 md:grid-cols-4 lg:grid-cols-5`.

## Состояния наличия

- Распроданное - приглушение, не зачёркивание: фото `opacity-50 grayscale-[35%]`, размеры-призраки `border-dashed text-gray-300`, серые пилюли статусов ("Esgotado nesta cor").
- Метка ESGOTADO - на активном свотче, не на всех.
- Вместо мёртвой кнопки - живое действие: зелёная "Avise-me quando chegar" в WhatsApp.
- Мало штук - подсказка `Só resta(m) N` в розовой пилюле.

## Фото

- Всегда `NuxtImg` с `sizes` и `format="webp"`; `sizes` начинать с брейкпоинта (`xs:45vw`), иначе в srcset попадает мусорный кандидат `0w`.
- `fetchpriority="high"` - только у LCP-кадра (первый слайд галереи, центр веера hero). Остальное `loading="lazy"`.

## Разное

- Тач-зоны мелких контролов расширять через `before:absolute before:-inset-2`, не увеличивая сам элемент. Не ставить `relative` в базовый класс компонента, который позиционируется пропом-классом снаружи.
- Grid-колонки с каруселями внутри - всегда `min-w-0`, иначе распирает страницу.
- Скролл-контейнеры с кольцами активных элементов - с запасом `p-1`, чтобы кольцо не резалось.
